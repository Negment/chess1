# chess1

ブラウザで動くチェスの解析・対局ツールです。Stockfish(エンジン)と Maia(人間らしい手の予想)を組み合わせて、手の候補や、相手の応手を調べられます。インストールは不要で、静的なファイルを配信すれば動きます。

## 主な機能

- **対局・配置**: 盤面で手を指す、駒を配置する(配置モードで、局面を作る)。
- **棋譜**: PGN、UCI、ICCF、FAN の形式で、読み込みと書き出し。
- **解析**: 最善手(Stockfish、または自作エンジン)、形勢(エンジンの評価と、簡易計算)、先読み、棋譜の解析と復習(手ごとの評価の損失)。
- **Maia**: 人間らしい手の予想と、相手のレートに応じた確率。
- **おまかせ**: レートの自動算出(棋譜の解析から、勝率の損失で推定)と、最適解の算出(Stockfishの評価と、Maiaの応手の予想を組み合わせた点数)。
- **棋風**: 指し方の好みを、白と黒それぞれに設定(白と黒を入れ替えられます)。
- **ルール**: キャスリングとアンパッサンを、設定でON/OFFできます(既定は標準どおりON)。

## 動かし方

Node.js が必要です(テストと、ローカルの配信に使います)。

```bash
npm test          # テスト(43本。計算の正しさを確かめる)
npm run test:e2e  # ブラウザでの動作確認(初回は npm i -D @playwright/test と npx playwright install chromium が必要)
npm run serve     # http://localhost:8080 で開く
```

GitHub Codespaces でも、そのまま動かせます。

```

js/engines.js       エンジンの呼び出し(Stockfish、自作、テーブルベース)、探索の順番待ち
js/app.js           盤面と操作の画面
js/review.js        形勢、対人の計算、棋譜の解析
js/kifu.js          棋譜の読み込みと書き出し

engines/maia/       Maia の実装(maia3-js。モデル重みは含まない)

```

## エンジンについて

- **Stockfish**: 候補手と評価の主な情報源です。`engines/stockfish/` にある `stockfish-19-single` を使います。読み込めないときは、自作エンジンに切り替わります。
- **自作エンジン**: Stockfish が使えないときの代わりです。強さは Stockfish より大きく劣ります。候補を1手しか返さないことがあります。
- **Maia**: モデルの重みは、リポジトリに含めていません。初回に、Hugging Face から取得します(5M は約 22MB、23M は約 92MB、79M は約 300MB)。取得後はブラウザに保存されます。
- **テーブルベース**: 7駒以下の局面で、Lichess のオンラインの API を使います。インターネットへの接続が必要で、局面が外部に送られます。

## 探索と時間

- **時間で止まる**: 深さの上限は設けていません。制限時間の中で、完了できた最も深い結果を使います。
- **次の深さを予測する**: 直前の深さにかかった時間から、次の時間を見積もります。間に合わないと判断したら、始めません。
- **猶予**: 実際の打ち切りは、目標の1.15倍です。完了していない深さの結果は使いません。
- **おまかせの予算**: 全体で6秒。候補ごとに残りを等分し、使い残しは次の候補に回します。
- **Stockfish**: 置換表は32MB、1スレッドで起動します。

## 候補の出どころ

最善手と対人・おまかせの結果には、候補の出どころ(Stockfish、テーブルベース、自作エンジン)が表示されます。Stockfishが使えず自作エンジンに切り替わった場合は、警告が出ます。

## テスト

`npm test` は次を確かめます。

- 手の生成が正しいか(標準的な局面の perft)
- 探索が詰みを正しく見つけるか(総当たりの正解と比べる)
- Stockfish の探索の順番待ちが、結果を混ぜないか
- おまかせの点数の計算が、設計どおりか

テストは、計算の仕組みが正しいことを確かめるものです。エンジンの強さや、Maia の予想が実際の対局で役立つかは、テストでは分かりません。

## 既知の制限

- 自作エンジンは補助用です。
- 対人・おまかせの点数は、Maia の予想の精度に依存します。その有効性は、まだ十分に検証されていません。
- Stockfish が使えない環境では、おまかせの候補が1手になり、比較ができません。
